Connection guide

Base endpoint: https://portal.turnlypros.com/api/integration-v1

Read leads or bookings
GET /api/integration-v1?resource=leads&limit=50
Authorization: Bearer YOUR_API_KEY

Use resource=bookings for bookings. Responses include data and next_cursor. Pass the cursor as after to get the next page. Use id to retrieve one record. Maximum 100 records per page and 60 requests per key per minute.

Create a lead
POST /api/integration-v1?resource=leads
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: your-unique-request-123

{"name":"Example Realtor","contact_email":"realtor@example.com",
 "contact_phone":"","sales_city":"Raleigh","sales_state":"NC"}

Requires leads:create. Use a unique Idempotency-Key per request and reuse it when retrying the same request. Matching email, or matching name and phone, returns the existing lead ID without changing it. New leads start unassigned with New status.

Verify signed webhooks

Compute HMAC-SHA256 using the webhook signing secret over X-Turnly-Timestamp + "." + raw request body. Compare it in constant time to the hexadecimal value after v1= in X-Turnly-Signature. Reject timestamps older than five minutes. Deduplicate on the event id; delivery is at least once. Return a 2xx status quickly. Redirects are not followed.

{"id":"event-uuid","type":"lead.updated","created_at":"…",
 "data":{"resource":"leads","resource_id":"lead-uuid"}}

Up to eight attempts with increasing delays. Pausing stops future events and cancels queued deliveries when processed. An in-flight delivery may finish. Receivers must use HTTPS, port 443, and public IPv4 DNS. Signing secrets depend on the server CRON_SECRET; coordinate secret rotation with your administrator.

Connect n8n

Use an HTTP Request node with Header Auth: header name Authorization, value Bearer YOUR_API_KEY. Store the key in n8n credentials. For events, create an n8n Webhook node, activate its workflow, and paste its production HTTPS URL above. Validate webhook signatures before processing events.
