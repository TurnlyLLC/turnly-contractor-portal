Agent referrals

Connect email and text sending

Your lead cards, referral links, personalized flyer, and bonus tracking work in the portal. Complete these account-owner steps to enable the Send info button’s delivery services.

1. Email — Resend

  1. Create or sign in to the Turnly account at Resend.
  2. In Domains, add turnlypros.com (or a dedicated sending subdomain). Add the exact verification DNS records Resend provides at your domain’s DNS host, then wait for Verified. Keep existing mail records unless Resend specifically requires a change.
  3. Choose a sender on that verified domain, for example Turnly <sales@turnlypros.com>.
  4. Create a dedicated server API key named “Turnly agent referrals.” The portal needs sending and email retrieval access for Check delivery; use Full access for this integration.
  5. Save the key in Vercel as RESEND_API_KEY and the sender as REFERRAL_FROM_EMAIL.

References: domain verification · API keys

2. Text messages — Twilio

  1. Create or sign in to Turnly’s Twilio account and complete the account and billing setup.
  2. Obtain an SMS-capable US number. For a local 10-digit number, complete Twilio’s US A2P 10DLC business/brand and campaign registration using Turnly’s real business information and the way agents agree to receive messages. Wait for approval.
  3. Create a Messaging Service (or use the one created during registration), associate the approved campaign, and add the number to its Sender Pool. Enable the service’s opt-out handling.
  4. Copy the Account SID and Auth Token from the account dashboard. Copy the Messaging Service SID, which starts with MG.
  5. Save them in Vercel as TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, and TWILIO_MESSAGING_SERVICE_SID.

Reference: Twilio registration steps. Imported phone numbers do not mark text permission as recorded. After an agent agrees, edit their card and check the text permission field.

3. Add credentials to the portal deployment

In Vercel, open the turnly-contractor-portal project → Settings → Environment Variables. Add the five values below to Production. Keep them server-only; never put keys in env.js, source control, or a lead card.

VariableValue
RESEND_API_KEYDedicated Resend API key
REFERRAL_FROM_EMAILTurnly <sales@turnlypros.com>, using your verified sender
TWILIO_ACCOUNT_SIDTwilio Account SID
TWILIO_AUTH_TOKENTwilio Auth Token
TWILIO_MESSAGING_SERVICE_SIDApproved Messaging Service SID

Then open Deployments and redeploy the latest production deployment so it receives the new variables. The existing Supabase server connection must remain configured.

Reference: Vercel environment variables.

4. Verify with your own test contact

  1. Open Admin → Agent Referrals. Expand “Flyer template & sending setup.” Email and Text should show Connected. This confirms credentials are present; the first test checks whether they work.
  2. Add a separate internal test lead with your own email and mobile number, and record your permission to receive texts.
  3. Open the lead and choose Preview flyer. Scan its QR code and confirm it uses that lead’s referral link. The signup form becomes usable when the agent is Active.
  4. Click Send info to send immediately to the primary email and phone. To use a saved alternative or send through just one channel, select Choose recipients, make your selections, and click Send flyer.
  5. The confirmation reports each service’s result. A confirmed provider acceptance sets the agent to Active. Failed, unconfigured, or uncertain results alone leave its status unchanged. If one channel succeeds and the other fails, the agent becomes Active and both results are shown.
  6. Use Check delivery in the lead’s delivery history. Accepted/queued means the provider received the request; Delivered means the provider reported delivery. Check the provider dashboard before retrying an uncertain result.

Email attaches the personalized PDF. Text sends links to the PDF and customer signup page. Importing leads never sends messages.

Referral bonus tracking

A client’s signup is attributed to the agent’s unique QR/link. In the agent card, link the customer’s first cleaning assignment and its eligible subtotal. The 10% bonus becomes earned only when that clean is completed and the customer has fully paid. Later cleans do not earn another referral bonus. Record bonus paid after you pay the agent; the portal tracks that payment but does not transfer funds.
